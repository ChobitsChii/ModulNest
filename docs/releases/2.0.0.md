# ModulNest 2.0.0

Veröffentlicht am 09.09.2026. Dies ist die erste stabile Version des
ModulNest-2-Modulsystems.

## Wichtigste Neuerungen

- Signierter Modul-Katalog mit elf unabhängig versionierten Produktmodulen.
- Sichere v1→v2-Adoption mit Code-Preflight, Backups und Datenerhalt.
- Unabhängige Modulupdates, Changelogs und „Alle aktualisieren“.
- Vollständiger Modul-Lifecycle inklusive Retain, Reinstall und Purge.
- Background-Lifecycle mit Fortschrittsanzeige für lange Operationen.
- Getrennte Modulverwaltung und Katalogoberfläche.
- Updatekanäle für Stable- und Vorabversionen.

Der Core enthält keine Produktmodul-ZIPs. Die Module werden unabhängig unter
[`ChobitsChii/ModulNest-Modules`](https://github.com/ChobitsChii/ModulNest-Modules)
veröffentlicht.
