# ModulNest 0.8.3 alpha

Veröffentlicht am 20.05.2026. Auth-Patch für Remember-Me und Passkeys/WebAuthn.

- Remember-Me funktioniert auch beim direkten WebAuthn-Login.
- Die Auswahl „Angemeldet bleiben“ wird im WebAuthn-Flow korrekt verarbeitet.
- Verbesserte WebAuthn-Login-Logs ohne Secrets oder Credential-Daten.
