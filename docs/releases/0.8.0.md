# ModulNest 0.8.0 alpha

Veröffentlicht am 15.05.2026. Führt das native Homepage-Modul ein.

- Administrierbare Startseitenblöcke mit Markdown, Feature-Listen und
  Modulübersicht.
- Sichtbarkeit für Gäste, Benutzer und Admins sowie flexible Blockbreiten.
- Sichere Rückfall-Startseite, solange die Homepage nicht veröffentlicht ist.
