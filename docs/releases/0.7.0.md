# ModulNest 0.7.0 alpha

Veröffentlicht am 12.05.2026. Erweitert den öffentlichen Modulumfang und legt
die erste Grundlage für Datenmigrationen.

- Neues Export-/Import-System für Moduldaten.
- Public-Module für Banking, Sneak Preview, Tools und Logs.
- Modulare Schemas für Clean Installs sowie `schema_migrations` und
  MigrationRunner.

[GitHub Release](https://github.com/ChobitsChii/ModulNest/releases/tag/v0.7.0)
