# ModulNest 2.0.1

Veröffentlicht am 09.09.2026. Dieses Patch-Release stellt die offizielle
Distribution auf die ModulNest-Mirror-Domains um.

## Änderungen

- Core-Updates werden standardmäßig über `updates.modulnest.de` verteilt.
- Der signierte Produktionskatalog wird standardmäßig über
  `repo.modulnest.de` geladen.
- Die bisherige offizielle GitHub-Katalogquelle wird beim Upgrade gezielt auf
  den offiziellen Mirror migriert; benutzerdefinierte Quellen bleiben erhalten.
- Die Updatekanal-Darstellung und der Disclosure-Button wurden dezent
  überarbeitet.
- Die Mirror-Skripte unterstützen einen stillen, cron-tauglichen Modus.
