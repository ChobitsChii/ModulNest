# ModulNest 2.0.0-rc.2

Veröffentlicht am 09.09.2026. **Release Candidate – noch keine Stable-Version.** ModulNest 1.3.0 bleibt der
empfohlene Stable-Release. RC.2 wird ausschließlich Installationen mit dem
Updatekanal **Stable + Vorabversionen** angeboten.

## Behoben

- Die v1→v2-Adoption liest bekannte Dateihashes und historische
  Migrationschecksummen aus signierten Modulmetadaten. Der Public-Core benötigt
  kein privates `modules-src` mehr.
- Fehlen Adoption-Metadaten oder sind sie ungültig, bleibt der Modul-Katalog
  erreichbar. Nur die betroffene Adoption wird sicher blockiert und eine
  Diagnose protokolliert.
- Die Updatekanal-Konfiguration verwendet eine kompakte, zugängliche
  Disclosure-Darstellung mit klaren Chevrons.

## Modulveröffentlichung

Die elf Produktmodule und der signierte Production-Katalog werden ab RC.2
unabhängig vom Core im öffentlichen Repository
[`ChobitsChii/ModulNest-Modules`](https://github.com/ChobitsChii/ModulNest-Modules)
veröffentlicht. Core-Releases enthalten keine Produktmodul-ZIPs mehr. Jedes
Modul kann damit unter seiner eigenen SemVer und seinem eigenen Tag aktualisiert
werden.

## Upgrade-Hinweis

RC.1 bleibt unverändert als historisches Prerelease erhalten. Das Upgrade von
RC.1 auf RC.2 behält den gewählten Updatekanal. Vor einer v1→v2-Adoption werden
weiterhin Originaldateien exakt geprüft; unbekannter oder lokal veränderter Code
wird nicht automatisch ersetzt.
