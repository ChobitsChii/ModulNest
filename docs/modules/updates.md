# Updates

**Zugriff:** Administratoren.

Prüft, bereitet vor und installiert offizielle ModulNest-Pakete. Standardmäßig
wird ausschließlich `stable.json` verwendet. Administratoren können für die
gesamte Installation zusätzlich Vorabversionen aus `prerelease.json` aktivieren;
Stable-Releases bleiben dabei weiterhin Kandidaten und haben bei höherer
SemVer-Version Vorrang. Downloads, SHA256-Prüfung, Backups, Wartungsmodus und
Recovery arbeiten fail-closed.
